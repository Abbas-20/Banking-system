Bank Management System
A console-based Bank Management System developed in C++ using Object-Oriented Programming (OOP) principles and a modular multi-file architecture.
Features
Secure user authentication and login system.
Role-based permissions for different users.
Client management (Add, Update, Delete, Find, and View Clients).
User management (Add, Update, Delete, and Manage Users).
Login activity tracking and logging.
Data persistence using text files.
Data Storage
The system uses text files as a lightweight database:
Clients.txt: Stores client information.
Users.txt: Stores user accounts and permissions.
LoginRegister.txt: Stores login history and activity logs.
